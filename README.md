# Автоматический Excel-отчёт по продажам

![report.bmp](https://github.com/user-attachments/files/35092103/report.bmp)


Скрипт на Python берёт таблицу продаж в формате Excel и за несколько секунд собирает из неё готовый отчёт: 
итоги по менеджерам, по товарам и по дням, доли в процентах и диаграмму. Вместо ручной обработки данных вы запускаете одну команду.

## Что делает отчёт
- Лист «По менеджерам»: сумма продаж каждого менеджера, доля в общих продажах (%), итоговая строка и столбчатая диаграмма
- Лист «По товарам»: суммы по пяти товарам и «Итого».
- Лист «По дням»: 31 день октября 2026 с суммами и «Итого».
- Аккуратное оформление: выделенные заголовки, итоги жирным шрифтом, подобранная ширина столбцов

## Состав проекта
- `make_data.py`: создаёт учебный файл `sales.xlsx` с вымышленными продажами чая и кофе (200 записей за месяц)
- `report.py`: читает `sales.xlsx` и создаёт готовый `report.xlsx`

## Как запустить
1. Установите Python 3.10 или новее
2. Установите библиотеку: `python -m pip install openpyxl`
3. Создайте тестовые данные: `python make_data.py`
4. Соберите отчёт: `python report.py`
5. Откройте файл `report.xlsx` в Excel, LibreOffice или Google Таблицах

## Как использовать с вашими данными
Положите свою таблицу рядом со скриптом под именем `sales.xlsx`. Столбцы должны идти в таком порядке: дата, менеджер, товар, количество, цена, сумма. 
Если у вас другая структура таблицы, скрипт можно быстро подстроить.

## Что можно доработать под вас

- Дополнительные диаграммы и сводные показатели

- Отправка готового отчёта на почту или в Telegram
